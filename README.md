# Nuclear Power Plant Visualization

Three.js-based interactive visualization for explaining the structure and working process of a pressurized water reactor nuclear power plant.

## Features

- Cutaway reactor containment and pressure vessel
- Reactor internals: core barrel, support plates, fuel assembly array, guide tubes, control rods, coolant inlet and hot outlet
- Animated neutron and heat-release markers in the core
- Primary loop, secondary steam loop, condenser cooling loop, turbine, generator, transformer, and grid output
- Step-by-step process tabs for fission, primary heat transfer, steam generation, power generation, and cooling
- Orbit camera controls, animation pause/resume, reset view, and flow speed control
- Responsive desktop and mobile layout

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```
